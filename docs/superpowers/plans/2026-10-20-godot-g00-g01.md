# Godot G00／G01 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 主控直接實作；依 repo 規則以獨立 reviewer 審查，不默認授權寫入型 subagent。

**Goal:** 正式替換引擎開發路線，然後以同一 Godot project 驗證 Windows x64／Web 雙匯出；不在本計畫移植完整 gameplay。

**Architecture:** G00 是獨立文件交付，保留 Unity 歷史與 Three.js 基準。G01 以 GDScript／Compatibility／single-thread Web 建最小工程與 fail-closed runner，實際兩平台匯出後前景驗證。兩期分開正式 review／授權 merge／post-merge gate。

**Tech Stack:** 現有 Node 22.22.0、OpenSpec 1.6.0；Godot 4.7.2 本機候選需官方 executable／templates provenance 核對，測試用 Node 內建 test runner 與 Godot headless SceneTree。瀏覽器採既有 Playwright 能力，不安裝新 runtime 或套件。

**Spec:** `openspec/changes/godot-threejs-migration/specs/godot-threejs-port/spec.md`；設計 `docs/engineering/GODOT_MIGRATION_DESIGN.md`。
