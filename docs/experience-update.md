# 本機遊戲體驗改善 — 2026-09-29

本輪以既有三百魏兵、程序化體素與合成音效架構為基礎，改善操作銜接、戰鬥選擇及畫面辨識。來源基準為 `dbd69269eb51460282eee573cb243cf2198e1fca`；體驗變更已提交為 `118f241`。後續加入中英介面；實際發布版本與上傳驗證以 `docs/itch-page.md` 的 release 紀錄為準。

## 可玩的變更

- 按住 J／滑鼠左鍵／手把普攻可連段；蓄力輸入優先，不被自動普攻覆蓋。
- 地面攻擊達到可取消時機且最後命中窗口結束後，可用方向輸入取消收招。
- 閃避開始 0.10 秒後接普攻施展「疾風突」。
- F／L1 防禦，方向輸入可原地轉向。正面一般格擋承受輕擊 25%、重擊 45% 傷害，背後不能格擋。
- 起防 0.16 秒內完美格擋可免傷、無雙 +12；0.72 秒內普攻施展「龍膽返」，放開防禦仍可接招。閃避或未格擋命中會清除反擊權。
- R／按下右搖桿可平滑回正鏡頭，滾輪縮放也經過平滑處理。
- 失焦自動暫停並清除排隊操作，回到遊戲仍保持暫停。
- HUD 顯示當前招式、六段普攻、可接蓄力技、連擊剩餘時間與無雙就緒提示。
- 趙雲增加盔翎、胸甲與槍飾；隊長增加三叉翎與識別色；防禦、疾風突與龍膽返有獨立姿勢。
- 加入貼地焦土／餘燼，降低戰鬥景深與泛光。蓄勢敵兵有地面預警圈，一般兵為金色、隊長為紅色；不改 AI 時機、世界配置或碰撞。
